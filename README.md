# ITI Trades Assistant

ITI ke trades ke liye calculators (Python + Streamlit): Turner/Machinist, Fitter,
Electrician, Welder, Electronics Mechanic, Refrigeration & AC, Plumber, Carpenter,
Mechanic Motor Vehicle/Diesel.

## Chalane ka tareeka
    pip install -r requirements.txt
    streamlit run app.py

Note: formulas aur ranges reference ke liye hain. Asli kaam me apne handbook / instructor se check karo.
